# De Letterdief

Een leesspel voor kinderen van 4 tot 6 jaar. Snaai de letterdief pikt letters uit woorden omdat hij zelf niet kan lezen.
Ren hem achterna, pak de goede letters terug en maak de woorden weer heel. 8 werelden volgens de lettervolgorde van
Veilig Leren Lezen, met klanken (mmm) in plaats van letternamen, een adaptief niveau en een woordenboek vol stickers.

**Spelen:** https://lpompen.github.io/letterdief/

1. Open de link één keer in Safari met internet en wacht tot het spel geladen is (ouders ⚙️ toont *Offline klaar*).
2. Kies Delen → Zet op beginscherm.
3. Open het spel vanaf het beginscherm; daarna werkt het ook zonder internet.

Stem: Piper TTS (nl_NL pim/ronnie). Lettertype: Andika (SIL Open Font License). Deze repository bevat alleen de
gepubliceerde spelbestanden (v1.1.0).
